== E1 (Low): the patch dropped D1's "history couldn't be loaded" state
$ npm run typecheck   (the patch alone, on main)
frontend/src/ui/shared.tsx(183,8): error TS2739: Type '{ bids: Bid[]; saleSupply: bigint; startTime: bigint;
account: string | null; explorer: string | null; }' is missing the following properties from type 'Props':
auction, historyUnavailable
Built on the code before D1, the new Bids section did not pass the two props D1 added. Because they are
required props, typecheck failed instead of the regression shipping. Fix (2d5ba74): useDashboard returns
historyUnavailable and the Bids section passes both props.

== E3 (Low): price-chart labels cut off on phones
At 390 px the redesign's larger axis labels (17 px) did not fit the chart's left padding: "0.00006" showed
as ".00006". Fix (26c78bf): the chart's SVG may draw past its padding. Checked in a 390 px frame: labels in
full, page 375 px wide, no horizontal scroll.
